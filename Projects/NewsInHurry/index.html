Problem Statement

Busy readers need signal, not noise. Raw news feeds across many sections are hard to scan; understanding how stories connect—and whether markets align—takes more time than most people have.

The app packages live NYT Top Stories, AI-ranked cards (breaking, trending, latest), and a multi-agent analysis layer so users get scannable headlines first and deeper synthesis when they want it.

What the Application Does

  • Fetches NYT Top Stories across home, business, arts, technology, world, and politics.
  • Orders stories as breaking → trending → latest and filters by a 6–48 hour window with optional sentiment filter.
  • Enriches articles with AI sentiment, impact labels, and tone-aware summaries (informational, opinion, or analytical).
  • Shows six cards per page with pagination; first page uses a 2+2+2 mix of breaking, trending, and latest.
  • Runs parallel section briefs, then a three-agent serial workflow for cross-section links, world mood, and news-vs-market validation.
  • Displays a Global Insight header marquee and full Signal Studio dashboard with QC metrics and downloadable PDF report.
  • Offers Dive deeper per article—a separate research agent with Wikipedia and Yahoo Finance tools.

Multi-agent workflow

Coordinated agents with clear roles, workflow integration, and UI-bound outputs (project documentation).

  • Section briefs (parallel) — short LLM summary per section packet before the main chain.
  • Agent 1 — cross-section themes, triggers, and propagation across desks.
  • Agent 2 — world mood score, market stance, and reasoning from Agent 1 plus sentiment counts.
  • Market snapshot — live Yahoo Finance data via yfinance (not an LLM).
  • Agent 3 — compares the news narrative to market tape; may call get_market_snapshot via OpenAI function calling.

Technical Architecture

Pattern: Shiny for Python single-page app; reactive state and in-memory caches in AppV1/app.py—no database.

  • UI — tabs, filters, cards, Signal Studio, marquee (ui/, modules/news_cards.py).
  • Data — NYT fetch, dedupe, breaking/trending/latest (modules/data_fetch.py, categorization.py).
  • AI enrichment — sentiment, impact, summaries (ai_services.py, impact_classifier.py).
  • Agents — workflow orchestration (agents/workflow.py, llm_client.py).
  • Research — per-article modal agent (research_agent/).

External services: NYT Top Stories API, OpenAI Chat Completions, Yahoo Finance (yfinance).

Deployment: Posit Connect (AppV1/Procfile); API keys via .env or environment.
